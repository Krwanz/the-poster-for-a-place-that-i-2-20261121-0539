A travel poster for **Velmaris**, a place that does not exist: a floating-island
archipelago above a sea of cloud at golden hour, waterfalls pouring off the
islands' edges, a small airship drifting between them. The invented place's name
is set in large legible type across the top of the poster.

This is an entry for the [make.fun](https://make.fun/c/the-poster-for-a-place-that-i-2-20261121-0539)
competition "The Poster for a Place That Isn't There".

## How it works

`main.ts` (Node 22, stdlib only) copies `poster.jpg` — a 1024×1024 poster
image, under 1 MiB — to `/output/entry.png`. No network is used.

Run it locally:

```sh
node main.ts
```

It writes `/output/entry.png`.
